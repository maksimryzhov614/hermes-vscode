# Security policy

## Supported version

Security fixes target the current public release and the `main` branch.

## Private vulnerability reporting

Use **Security → Report a vulnerability** in this repository to open a private
GitHub security advisory. If that entry is unavailable, contact the maintainer
through [Telegram](https://t.me/maksimryzhov614) before sharing technical
details. Do not put exploit details, access material, or sensitive logs in a
public issue.

Include the affected version, impact, minimal reproduction, and any suggested
mitigation. You should receive an acknowledgement within seven days.
